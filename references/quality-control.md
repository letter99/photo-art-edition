# Quality Control

## A — Poster
- [ ] independent asset
- [ ] vertical 3:4
- [ ] photo remains recognizably photographic
- [ ] master illustration is unchanged in identity
- [ ] approximate 50/50 vertical zoning
- [ ] typography, if present, is restrained

## B — Color Sticker
- [ ] independent asset
- [ ] PNG
- [ ] strict RGBA mode
- [ ] real transparency outside sticker
- [ ] no poster-only typography
- [ ] warm-white die-cut border follows silhouette
- [ ] master identity preserved
- [ ] no unintended rectangular background

## C — Monochrome Sticker
- [ ] independent asset
- [ ] PNG
- [ ] strict RGBA mode
- [ ] real transparency outside sticker
- [ ] same silhouette as B
- [ ] same composition and subject relationships
- [ ] color replaced by black ink / paper white expression
- [ ] no unintended rectangular background

## Consistency checks
Compare A/B/C against the locked master on:
- subject identity
- relative positions
- scale relationship
- silhouette
- line character
- visual mood

## Decision
ACCEPT only when structural constraints and visual identity both pass.
If a problem is local, EDIT. If identity is fundamentally broken, REGENERATE from the locked reference rather than rewriting the entire design brief.
