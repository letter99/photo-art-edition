# Dimension Adaptation

The output geometry follows the source photograph. First apply EXIF
orientation, then classify the usable image as portrait, landscape or
panoramic. Choose one layout family and keep it consistent across A/B/C.

## Portrait source

- Default A: vertical 3:4 poster.
- Use stacked photo and Master zones with generous margins.
- B/C may use a vertical or compact square-ish sticker sheet if that better
  preserves the selected motifs without crowding.

## Landscape source

- Default A: horizontal 4:3 or 3:2 poster.
- Prefer side-by-side photo/Master zones when the horizon and lateral space are
  important; use stacked zones only when the scene reads vertically.
- B/C should use a horizontal or square-ish sheet with enough separation for
  every motif to remain independently readable.

## Panoramic source

- Default A: horizontal 3:2 poster with a wider photographic zone.
- Preserve the visual anchor and horizon; crop only disposable side detail.
- Do not stretch or squeeze the photograph to fit a portrait template.

## Shared rules

- Never rotate the scene to satisfy a template.
- State the selected ratio, canvas size and zone arrangement in the internal
  production record before generation.
- If the source orientation is ambiguous, use the EXIF-corrected display
  orientation and the composition's longer visual axis.
