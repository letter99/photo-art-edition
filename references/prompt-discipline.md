# Prompt Discipline

## Principle

Detailed analysis is for reasoning. The image-model prompt is a selective
creative brief.

Do not paste the full Scene Map, Memory Thesis, Visual DNA, object inventory,
or all QA rules into the generation prompt. Too many simultaneous constraints
turn a memory-led illustration into a literal checklist or a finished
landscape illustration.

## Master prompt contents

Usually include only:

1. the subject
2. one decisive relationship
3. the emotional memory
4. the atmosphere
5. a restrained drawing language
6. one negative-space or scale instruction

## Prompt pattern

```text
A quiet, sparse editorial memory of [subject] in [decisive relationship].
Preserve the feeling of [emotional memory] and [atmosphere]. Use [restrained
drawing language] with [limited color behavior] and generous [paper/space].
Let secondary details fade.
```

## Avoid

- exhaustive object lists
- exact instructions for every foreground, midground and background element
- repeated synonyms for the same style
- forcing every field of a YAML analysis into the prompt
- more than one or two optional environmental cues
- turning emotional interpretation into decorative text

## Evaluation

At thumbnail size, compare the source and Master. Literal correspondence is
not required, but the Master should evoke the same emotional direction and
retain the same visual anchor.
