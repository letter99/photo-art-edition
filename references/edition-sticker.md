# B — Color Art Sticker

## Deliverable
One independent transparent-background PNG.

Required file properties:
- PNG
- RGBA
- real alpha transparency outside the sticker

## Operation
Locked Master Illustration
→ isolate
→ remove poster-only elements
→ crop/rebalance excess page space
→ natural die-cut silhouette
→ subtle warm-white sticker border
→ transparent exterior

## Preserve
- subject identity
- composition
- silhouette relationship
- line language
- color relationships
- visual character

## Short prompt pattern
> Turn the locked master illustration into a refined die-cut art sticker. Preserve the exact illustration, proportions, linework and color relationships. Remove poster-only typography and excess page space. Add a subtle warm-white paper border following the natural silhouette. Keep the area outside the sticker fully transparent.
