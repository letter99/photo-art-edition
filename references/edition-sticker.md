# B — Color Art Sticker

## Deliverable
One independent transparent-background PNG.

Required file properties:
- PNG
- RGBA
- real alpha transparency outside the sticker

## Operation
Scene Map + locked Master
→ select a small set of meaningful source-derived motifs
→ abstract each motif into a compact same-medium shape
→ vary scale and arrange as a coherent sticker sheet
→ remove poster-only elements and excess page space
→ natural die-cut silhouette for each motif
→ subtle warm-white sticker borders
→ transparent exterior

This is motif abstraction and recomposition, not a rectangular crop of the full
hand-drawn Master. Use only the number of motifs the source scene can support;
do not pad the sheet with generic decorative objects.

## Preserve
- subject identity
- composition
- silhouette relationship
- line language
- color relationships
- visual character

Also preserve individually legible, separated and intentionally scaled motifs;
the sticker set must reflect the source scene rather than the entire Master crop.

## Short prompt pattern
> Turn the locked master illustration into a refined die-cut art sticker. Preserve the exact illustration, proportions, linework and color relationships. Remove poster-only typography and excess page space. Add a subtle warm-white paper border following the natural silhouette. Keep the area outside the sticker fully transparent.
