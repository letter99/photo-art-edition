# Illustration Direction

## Core idea
The illustration is a remembered drawing, not a literal redraw.

Use this mental model:
> What would an observant illustrator remember after looking at the photograph for a short while?

## Selection system
### Must Keep
Elements required for recognition and core meaning.

### Optional
Environmental suggestions that clarify place or mood.

### Disposable
Photographic details that add description but not identity.

## Five-fact test
Ask:
> If only five visual facts could remain, which five would preserve recognition and feeling?

## Preferred visual behavior
Aim for a quiet, spacious editorial watercolor image: let the subject sit
modestly in a large field of breathing room, retain only the marks that carry
recognition and feeling, and let the surrounding place appear through a few
suggestive gestures. Use low-saturation, source-derived color on tactile paper,
with slightly irregular hand-made edges and restrained pigment variation. Fine
ink or pencil accents may support the watercolor, but do not turn the result
into a botanical study, a literal travel sketch, or a photographic filter. The
reference image establishes the level of quietness and reduction, not a fixed
subject, layout, or object list. Text is optional and should appear only when
requested.

## Avoid over-specifying
Do not create a checklist such as “include water, mountain, shoreline, stones, foliage...” unless a specific element is essential. The model should decide how little is enough from the director's selection.

## Short master prompt pattern
> Create a small, quiet editorial illustration of [scene], as if an observant illustrator had casually remembered it by hand. Focus on [must-keep relationship]. Use a restrained tactile visual language with [color behavior] and generous breathing room. Keep the subject [scale/negative-space instruction]. Let the environment appear only as a few suggestive gestures.

## Revision pattern
Fix only the detected drift. Example:
> Make the illustration quieter and more economical. Reduce the subject scale and secondary environmental detail, leaving more warm paper visible.
