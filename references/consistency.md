# Consistency Strategy

## 1. Semantic Lock
Scene Map + Visual DNA define the subject and intended memory.

## 2. Reference Lock
The automatically selected Master Illustration becomes the canonical visual
reference.

## 3. Prompt Lock
Downstream prompts should be short and operational. Repeat invariants; state only the current change.

## 4. QA Lock
No asset is final until visual and file checks pass.

## Exploration vs Production
### Exploration
Use multiple candidates. Test simplification, scale, line quality and negative space.

### Production
Once the master is selected, stop broad exploration. Reuse the master and make
only controlled transformations.

## Change Budget
Master revision: max 1–3 meaningful changes per pass.
B: crop/isolation/border/spacing only.
C: monochrome rendering only.

## Stability principle
Prefer:
- reference reuse over memory
- derivation over re-generation
- surgical edits over whole-image rewrites
- identity consistency over pixel identity

Controlled variation is acceptable when the operation requires it.
